# Kildekartet er erstattet av tiltaksregisteret

Kildekartet er erstattet av
[`docs/dulting-tiltaksregister.md`](dulting-tiltaksregister.md).

Tiltaksregisteret viser råkort, intensjon, tiltaksklynge, status og kommentar
for alle DULT-kortene. Bruk det når du vil se hva som ligger bak en
tiltaksklynge i Mural.
