# Målmodell og virkningshypotese for første tiltakspakke

**Beslutning:** Første tiltakspakke måles først på nærliggende handlinger og kvalitetstegn, ikke på dokumentert effekt på sykefravær. Dette dokumentet beskriver virkningshypoteser for første test og brukes som input til analysemodell i #23 og tiltakspakkevisning i #14.

## 1. Overordnet mål og oppdragskontekst

AID-oppdraget ønsker redusert sykefravær ved at arbeidsgiver følger
tilretteleggingsplikten og arbeidsgiver og sykmeldt følger
medvirkningsplikten.

For første tiltakspakke er målet mer avgrenset:

- få arbeidsgiver tidligere i gang med relevant oppfølging
- få flere til å ta stilling til behov for oppfølgingsplan
- få flere relevante planer startet og delt tidligere der plan er riktig tiltak
- unngå at løsningen blir en snarvei bort fra oppfølgingsplikt

Dette er **virkningshypoteser**, ikke dokumentert effekt. Sykefravær og
gradering er distale effektmål og skal ikke være primær KPI i første test.

## 2. Virkningshypoteser H1/H2

### H1. Tidligere oppfølging hos arbeidsgiver

Hvis arbeidsgiver får et tidsriktig signal og en enkel behovsvurdering i riktig
kontekst, kan flere komme tidligere i gang med oppfølgingsplan, oppfølging og
samtale med den ansatte. Det kan bidra til tidligere oppfølging og på sikt
påvirke sykefravær.

### H2. Bedre informasjonsgrunnlag for fastlege

Hvis flere oppfølgingsplaner starter og deles tidligere med lege eller Nav, kan
flere fastleger få relevant informasjon om arbeidssituasjon, arbeidsoppgaver og
tilretteleggingsmuligheter tidligere. Det kan gi bedre grunnlag for vurdering
av videre sykmelding og gradert sykmelding. Det mest nærliggende tegnet på H2
er derfor at relevante planer faktisk blir delt med lege eller Nav, særlig
tidlig deling før relevant legekontakt hvis dette kan måles på en trygg måte.

## 3. Målenivåer

| Målenivå | Hva vi mener |
|---|---|
| Aktivitet | Om brukeren gjør en konkret handling, som å åpne relevant side, starte vurdering, starte plan eller dele plan. |
| Kvalitet | Om handlingen ser ut til å være meningsfull og forstått, ikke bare gjennomført. |
| Guardrails | Uønskede utslag vi må følge med på, som feilbruk, støy, misforståelser eller uheldig press. |
| Overordnet effekt | Mer langsiktige utfall som tidligere oppfølging, flere relevante planer delt med lege, gradering og sykefravær. |

## 5. Hva kan måles med eksisterende data

Disse tegnene kan i stor grad kobles til eksisterende domene- og hendelsesdata,
eller til data som allerede er nevnt som tilgjengelige:

- sykmeldingstidspunkt og varighet
- planstart
- plan-deling
- sykmeldingsgrad og endringer i gradering
- utvikling i sykefravær på aggregert nivå

Disse målene er mest nyttige som:

- grunnlag for populasjonsavgrensning
- sammenligning før og etter
- overordnede effektmål over tid

Eksisterende data er ikke nok alene til å si om brukeren **forsto** signalet,
hvorfor et valg ble tatt, eller om "plan trengs ikke nå" ble brukt riktig.

## 6. Hva krever survey eller ny instrumentering

### Ny instrumentering

Trengs for å måle første test på nærliggende handlinger:

- om signalet ble vist
- om arbeidsgiver åpnet relevant personside fra signalet
- om behovsvurderingen ble startet og fullført
- hvilket utfall som ble valgt i behovsvurderingen
- om bruker gikk videre til planstart etter vurdering

### Survey

Trengs for spørsmål vi ikke kan lese ut av atferdsdata alene:

- om arbeidsgiver forsto hva som var forventet
- om teksten opplevdes tydelig og relevant
- om signalet kom på riktig tidspunkt
- om brukeren opplevde valget "plan trengs ikke nå" som trygt og forståelig
- om løsningen støttet samtale og oppfølging, ikke bare registrering

## 7. Måledata og personvern

Måleoppsettet skal være dataminimert og skille tydelig mellom atferdssignaler og
innhold om helse eller arbeidsevne.

- Mål primært steg i flyten og valgte utfall, ikke fritekst.
- Ikke innfør fritekst som målegrunnlag i første test.
- Ikke bruk helseopplysninger eller sensitive detaljer som analysefelt uten egen
  avklaring.
- Rettslig grunnlag og behandlingsgrunnlag for ny produktinstrumentering,
  survey eller kobling mot fagsystemdata må avklares før implementering og
  analyse.
- Bruk aggregert analyse for distale effektmål som gradering og sykefravær.
- Survey må avgrenses til det som trengs for å forstå handling, kvalitet og
  eventuelle guardrails.

Pliktetterlevelse kan bare måles indirekte i første omgang, gjennom handlinger i
flyten, relevante delinger og eventuelt survey. Det må ikke fremstilles som et
fullgodt mål på faktisk etterlevelse.

## 8. Input til #23 og #14

### Input til #23 analysemodell

Analysemodellen bør minst kunne representere:

- tiltakspakke
- hovedklynge eller støttekomponent
- målenivå: aktivitet, kvalitet, guardrail, overordnet effekt
- måletegn
- datakilde: eksisterende data, ny instrumentering eller survey
- kobling fra måletegn til én eller flere virkningshypoteser
- markering av kunnskapshull og hva som må avklares

### Input til #14 tiltakspakkevisning

Tiltakspakkevisningen bør minst kunne vise:

- at første test består av to hovedklynger: **Tidsriktig signal** og
  **Behovsvurdering i Dine sykmeldte**
- at **Støttende tekst og forståelse** er en støttekomponent, ikke egen hovedtest
- måletegn per klynge, gruppert etter aktivitet, kvalitet, guardrails og
  overordnet effekt
- hva som kan måles med eksisterende data, og hva som krever survey eller ny
  instrumentering
- hvilke deler som fortsatt er kunnskapshull og må avklares før tolkning
