# Filbasert datalag

`data/` er reservert for strukturert, versjonert innhold i MVP-en.

## Grenser

- Ingen persondata
- Ingen diagnosegrupper
- Ingen konkrete saker eller saksnære eksempler
- Ingen små eller sårbare segmenter
- Ingen produksjonsdata

## Retning

MVP-en skal bruke YAML og/eller JSON for strukturert innhold, og eventuelt
Markdown for utfyllende begrunnelser. Denne første leveransen oppretter bare
mappe- og dokumentasjonsstruktur, ikke seed-data.
