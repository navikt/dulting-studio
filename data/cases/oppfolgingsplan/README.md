# Oppfølgingsplan

Dette er første case i `dulting-studio`.

## Innhold i mappen

- `case.json` — overordnet case, problem, hypotesegrunnlag og governance
- `tiltak/*.json` — illustrative enkelttiltak med EAST, Fogg og FORGOOD
- `tiltakspakker/*.json` — illustrative tiltakspakker med aggregert FORGOOD

## Viktig

Innholdet i denne mappen er kun illustrativt og skal brukes til struktur,
validering og tidlig UI.

- Ikke legg inn reelle tiltak fra Mural eller workshop
- Ikke legg inn personopplysninger, diagnosegrupper eller konkrete saker
- Ikke legg inn små eller sårbare segmenter
- Behold innholdet på generelt, redaksjonelt nivå
